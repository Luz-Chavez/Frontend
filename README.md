# Documentación de rutas principales

A continuación se detallan las rutas principales para el acceso y registro en la aplicación:

## Acceso (Login)

- **URL:** [http://localhost:5173/login](http://localhost:5173/login)

## Registro de Superadmin

- **URL:** [http://localhost:5173/superadmin/register](http://localhost:5173/superadmin/register)

---

Estas rutas funcionan por defecto en el entorno local utilizando Vite.

---

## Guía para iniciar el proyecto

1. **Accede a la carpeta del frontend**

   ```bash
   cd Frontend/frontend
   ```

2. **Instala las dependencias**

   ```bash
   npm install
   ```

3. **Inicia el proyecto en modo desarrollo**

   ```bash
   npm run dev
   ```

4. **Accede a la aplicación**
   - Abre tu navegador y entra a: [http://localhost:5173](http://localhost:5173)

---

Si tienes problemas, asegúrate de tener instalado Node.js y npm en tu sistema.
